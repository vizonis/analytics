6

Business Logic — CASE WHEN

CASE WHEN is how you translate business rules into SQL. Categorizing, bucketing, flagging — it all starts here. Most interview questions involve CASE WHEN.

Q44

Create a column "delay_status" with these rules: 0 minutes → 'On Time', 1–15 → 'Minor Delay', 16–60 → 'Moderate Delay', >60 → 'Severe Delay'. Count flights in each category.

Q45

Create a "price_segment" column: ≤3000 → 'Budget', 3001–6000 → 'Standard', 6001–10000 → 'Premium', >10000 → 'Luxury'. Count flights per segment.

Q46

Create a "load_category" based on load_factor: <0.5 → 'Low', 0.5–0.75 → 'Medium', 0.75–0.9 → 'High', >0.9 → 'Full'. Find average delay for each category.

Q47

Flag flights as 'Red Eye' if scheduled_departure is between 22:00 and 05:00, else 'Regular'. How many Red Eye flights exist?

Q48

Create a "revenue_tier" for each route: calculate total route revenue, then label top 3 as 'Platinum', next 5 as 'Gold', rest as 'Silver'.

8

Advanced SQL — Window Functions

Window functions (RANK, ROW_NUMBER, running totals) separate senior analysts from juniors. These questions test if you can think beyond basic GROUP BY. Optional but highly recommended.

Q55

Using ROW_NUMBER(), find the most expensive flight for each route (departure → arrival). Show flight_id, route, ticket_price.

Q56

Rank all flights within each route by delay (worst first) using RANK(). Show only the top 3 most delayed flights per route.

Q57

Calculate a running total of daily revenue (ticket_price × passenger_count) ordered by date. Show date, daily revenue, and cumulative revenue.

Q58

For each flight, find the difference in ticket price from the average price of that route. Use a window function with AVG() OVER(PARTITION BY route).

Q59

Use NTILE(4) to divide all routes into 4 quartiles based on total revenue. Show route, total revenue, and quartile number.

Q60

For each month, find the previous month's total revenue using LAG(). Show month, current revenue, previous month revenue, and month-over-month difference.

9

Real Business Case Questions

These are the questions a VP of Operations or Chief Commercial Officer would actually ask in a meeting. Write production-quality queries for each.

BC1

What are the most profitable routes?

Calculate total revenue per route. Show top 10 routes with revenue, average load factor, average delay, and total passengers. The business wants to know which routes to prioritize.

BC2

Which airports face maximum delays?

Analyze delays from both departure and arrival perspectives. The operations team needs data to decide where to allocate more ground staff and resources.

BC3

Does higher ticket price correlate with fewer delays?

Compare average delays across price segments (Budget, Standard, Premium, Luxury). The pricing team wants to know if premium pricing is justified by better on-time performance.

BC4

Which booking channel generates the most revenue?

Analyze total revenue, average ticket price, passenger volume, and average load factor per booking channel. The marketing team wants to know where to invest their budget.

BC5

How does weather impact delays and revenue?

For each weather condition, calculate average delay, % of flights delayed, total revenue, and average load factor. The operations team needs evidence to justify weather disruption policies.

BC6

Which routes should we consider cancelling or reducing frequency?

Find routes with low load factor (<60%), high average delay (>30 mins), and low revenue. These are the underperformers the network planning team wants to review.

BC7

Create a monthly executive dashboard summary

For each month, show: total flights, total passengers, total revenue, average ticket price, average delay, % on-time flights, and average load factor — all in one query.
