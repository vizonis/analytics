Formatting — Table

Format pane → Grid: toggle zebra striping (alternating row colors), set row padding, adjust font size. Zebra striping dramatically improves readability for tables with 20+ rows.

Cell Elements — Data Bars

Format → Cell Elements → Data Bars → pick Salary column. Bars show relative magnitude inline. Set bar color to acid green, direction Left-to-Right, show value at end.

Cell Elements — Icons

Format → Cell Elements → Icons → pick Status column. Map "Active" to green check, "InActive" to red X. Icons replace text and instantly convey status.

Conditional Formatting — Font Color

Format → Conditional Formatting → Font Color → Salary > $200,000 → set acid green. Salary < $75,000 → set red. Draws attention to outliers automatically.

Matrix vs Table

Table = flat rows. Matrix = rows + columns cross-tabulation. Matrix automatically adds subtotals and grand totals. Use Matrix when you need to compare two dimensions.

Data Bars in Matrix

Same as Table — Cell Elements → Data Bars. Works on value cells. The bars automatically scale within each column, making cross-column comparison easy.

Conditional Font Color in Matrix

Active count → green. InActive count → red. Total → white bold. Set per-field conditional formatting in the Format pane under "Cell elements."

Subtotals & Grand Totals

Format → Subtotals → Per row level / Per column level. Toggle on/off independently. Style subtotal rows with purple accent to distinguish from data rows.

Turn On Drill

Select visual → Format pane → Drill down → "On". Your visual must have a hierarchy in the axis (Country → City → Employee). Drag multiple fields into the Axis well to create hierarchy.

Drill One Level Down

Click the drill down arrow in the visual header (or double-click a bar). Moves one level deeper in the hierarchy. breadcrumb appears at top to show your path.

Expand All Levels

Click the expand icon (double-down arrows) in the visual header. Shows ALL levels at once — Country, City, and Employee rows visible simultaneously. Great for print/PDF exports.

Drill Up

Click the drill up arrow to go back one level. Or use the breadcrumb at the top of the visual to jump to any level directly. The hierarchy path shows: "Country > Seattle > [Employee]"

Chapter 04

LINE CHART

The go-to chart for trends over time — monthly hires, revenue growth, attrition rate

Line Chart — Monthly Hires Trend (Smooth Interpolation)
X Axis

Drag Hire Date (Month) to X Axis. Format → X Axis → Type = Continuous (not categorical). Set Start/End values. Show axis title "Month".

Y Axis

Drag Hires Count to Y Axis. Format → Y Axis → Start at 0. Set axis title "Number of Hires". Show gridlines for readability.

Data Labels

Format → Data Labels → On. Position: Above. Show only for high/low points to avoid clutter. Use "Custom" label to show values conditionally.

Interpolation Type — Smooth

Format → Lines → Interpolation = Smooth (Bezier). Creates curved lines instead of sharp angles. Best for showing trends when data has fluctuations. Straight = angular default.

Line Chart — Secondary Y Axis
Secondary Y Axis

Drag a second measure → Format → "Enable secondary Y axis." Left axis = Hires (green line). Right axis = Attrition % (purple dashed line). Different scales on same chart.

Legends

Format → Legend → Position = Bottom/Top/Left/Right. Single legend = one entry per line. Click legend items to toggle series visibility. Set legend title for clarity.

Area

Area

Single series with filled area below the line. Best for showing cumulative totals or volume over time. Fill opacity: 15-20% for readability.

Stacked Area

Multiple series stacked on top of each other. Shows both individual contribution AND total. Drag multiple measures to Values. Format → "Stacked area."

Stacked % Area

Each series shows as percentage of total (always 0-100%). Perfect for composition analysis — "What % of hires come from each source?"

Horizontal Bar

Best when labels are long (city names, job titles). Bars go left-to-right. Sort by value descending for impact.

Vertical Bar

Classic bar chart. Best when labels are short (months, categories). Bars go bottom-to-top.

H/V Stacked

Multiple series stacked. Shows total + breakdown. E.g., Active + InActive stacked per City = total headcount + composition.

H/V Stacked %

Each bar = 100%. Series show % of total. Perfect for "What % Active vs InActive per City?"

Sort Bars

Three-dot menu on axis → Sort descending. Or drag a measure to "Sort by column" in the visual's sorting options.

Bar Formatting

Set bar colors per series. Add data labels inside bars (center position). Adjust bar width to 60-80% for spacing between bars.

Four chart families that complete your visual toolkit

Combo Chart — Line + Clustered Column
Combo Chart

X Axis: Month. Primary Y (columns): Hires count. Secondary Y (line): Attrition %. Format → "Combo chart" → choose "Line and clustered columns." Each axis has its own scale.

Combo Stacked

Same but with stacked columns. Two series on primary Y (Active + InActive stacked), one on secondary Y (line). Use when you need both composition and trend in one visual.

Pie / Donut / Treemap
Pie

Pie / Donut

Pie: Full circle. Donut: Ring with center hole (show KPI in center). Both: Details → enable "Donut" toggle. Use for 5-7 categories max.

Treemap

Nested rectangles showing hierarchy. Size = value. Color = category. Perfect for budget allocation or headcount by department.

Chapter 08

ADVANCED CHARTS

Ribbon Chart
Ribbon Chart

Shows how multiple categories change over time. Each ribbon = one category's trend. Thicker ribbon at a point = higher value. Add to "Line and stacked column" family. Needs date + category + value fields.

Waterfall Chart
Waterfall Chart

Shows cumulative effect of sequential changes. Green = increase, Red = decrease. Final bar = total. Add under "Other chart" category. Needs: Category, Start value, End value (or auto-calculated).

Funnel Chart
Funnel Chart

Shows a pipeline: Applications → Screened → Interviewed → Offered → Hired. Each stage gets narrower. Add under "Other chart." Sort stages by count descending. Conversion % shown between stages.

Scatter Plot
Scatter Plot

X Axis = Salary, Y Axis = Tenure. Each dot = one employee. Reveals correlation patterns. Add trend line in Analytics pane. Use color saturation for a third measure (e.g., Bonus %).

Chapter 09-11

GEO · KPI · AI CHARTS

Filled Map
Filled Map

Location → City. Size → Count. Color → Avg Salary. Only works with recognized geographies.

Bubble Map
Bubble Map

Location → City. Size → Hires (bubble size). Color → Avg Salary. Bubbles = proportional circles on map.

Gauge / KPI
Gauge Settings

Value: current metric. Min: 0. Max: 100 (or target). Target line: dashed red line. Color rules: <50% red, 50-80% yellow, >80% green.

AI/ML Visuals

Key Influencers

Analyzes what factors influence a metric (e.g., "What drives Employee Status = InActive?"). Shows top influencers ranked by impact strength. Add to report → select target measure and field to analyze.

Decomposition Tree

AI-powered breakdown tree. Click "+" to split by any dimension. Splits Salary → by Country → by City → keeps drilling. AI chooses the split that explains the most variance.

Q&A Visual

Natural language query box. Users type questions, AI generates visuals. Train: Set synonyms (Salary = Compensation). Suggest: Enable suggested questions card for users.

Card Formatting

Background color, font size, label display. Accent bar = colored bar on left edge (Format → Card → "Show accent bar").

Border — Rounded Rectangle

Format → Card → Border → Rounded corners: 12px. Adjust border width and color. Remove border entirely for minimal look.

Shadow + Glow

Format → Effects → Shadow: 4px offset, 8px blur. Glow: increase blur to 20px + add border color match for neon effect.

Multi-Row Card

New Card visual → Add multiple fields to "Fields" well. Each field gets its own row. Best for KPI dashboards with 4-6 metrics side-by-side.

Image as Logo

Insert → Image → Place top-left. Resize to ~150x40px. Set page background = dark color for the logo to stand out. Lock position so it doesn't move accidentally.

Dashboard Title

Use a Text Box (Insert → Text Box) for the dashboard title — more styling control than page title. Syncopate font, acid green, large size. Place below logo.

Interaction — Edit Interactions

Format → Edit Interactions → Select visual A → click "none" on visual B → A won't filter B when clicked. Crucial for KPI cards — clicking a card shouldn't filter the trend chart below it.

Filter → Disable Interactions

Edit Interactions → set a slicer to "None" on a card → slicer still works but clicking card doesn't affect anything. Or disable slicer visuals from being filtered by other visuals.

Drill Through to Another Page

Right-click visual → Drill through → "City Detail Page." Create a target page. User clicks Seattle bar → navigates to Seattle detail page with pre-filtered data. No bookmark configuration needed.

Click a button → Bookmark activates → selected visuals show/hide → dashboard layout changes without navigating to a new page

Add Bookmarks

View tab → Bookmarks Pane → "Add". This captures the current state of ALL visuals (filters, selections, visibility). Name it meaningfully: "Overview", "By City", "Attrition View".

Add Button

Insert → Buttons → choose shape. Add to canvas. In the button's Action pane → Type: Bookmark → select which bookmark to activate on click. Style the button (fill, text, border-radius).

Configure Button

Button action → Bookmark → pick bookmark name. On click (not hover). Set button style: outline or filled. Add tooltip text for clarity. Group buttons with Shift+click for radio behavior.

Show/Hide with Selections

Each bookmark captures which visuals are visible. View → Bookmarks → select bookmark → some visuals hide. This is the core of dynamic dashboards — one page, multiple views.

Chapter 15

ROW LEVEL SECURITY

Complete step-by-step: Add Roles → Write DAX → Test → Publish

RLS Flow: Add Role → DAX → Test → Publish
1
Modeling → Manage Roles → "Add Role"

Create role name. Select table. Enter DAX filter expression.

2
DAX Editor — Write Filter

[HR][City] = LOOKUPVALUE(UserTable[City], UserTable[Email], USERPRINCIPALNAME())

3
Filtering Shelf → Assign Users

Members tab → Add users/roles. Map email → role. Security tab → add RLS role to workspace.

4
Manage Roles → "View as Roles"

Desktop only! Select role → preview as that user → verify data filtering is correct before publishing.

Common RLS Mistakes

Using CALCULATE inside RLS — RLS is already a filter context. No CALCULATE needed. Just return a table expression directly.

Testing only in Service — RLS doesn't work in Power BI Service preview. Test in Desktop with "View as Roles."

Not assigning users in workspace — Even with perfect DAX, if users aren't mapped to roles, everyone sees everything.

RLS Best Practices

Use a separate UserMap table (Email → Role/Region/City) — never hardcode emails in DAX.

Test with 3-4 different user scenarios before publishing. Document expected behavior.

For dynamic RLS with hierarchies, use PATHITEM and ISINSCOPE to handle drill-down filtering.
